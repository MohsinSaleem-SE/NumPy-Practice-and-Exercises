# NumPy Practice and Exercises 🧮

A collection of Jupyter Notebook exercises and hands-on practice sessions focused on learning and strengthening my skills in **NumPy**, a fundamental Python library for numerical computing and data analysis.

This repository documents my learning journey through five practice rounds, covering NumPy arrays, indexing, slicing, mathematical operations, statistical functions, data manipulation, missing-value handling, and array memory concepts.

## 🎯 Objectives

- Build a strong foundation in NumPy for data analysis and scientific computing.
- Practice working with one-dimensional and multidimensional arrays.
- Understand array indexing, slicing, filtering, and manipulation.
- Perform mathematical and statistical operations on numerical data.
- Learn how to handle missing values in arrays.
- Strengthen problem-solving skills through hands-on coding exercises.

## 📚 Topics Covered

### 1. NumPy Array Fundamentals
- Creating NumPy arrays using `np.array()`
- Generating sequences with `np.arange()`
- Reshaping arrays using `reshape()`
- Generating random integer arrays with `np.random.randint()`
- Understanding array properties using `dtype`, `ndim`, and `shape`

### 2. Indexing, Slicing, and Filtering
- Accessing individual array elements
- Slicing one-dimensional arrays
- Accessing rows, columns, and subarrays in two-dimensional arrays
- Using Boolean conditions to filter array elements
- Applying fancy indexing to select specific elements

### 3. Mathematical and Statistical Operations
- Performing element-wise addition, multiplication, and division
- Calculating dot products using `np.dot()` and the `@` operator
- Applying scalar operations to arrays
- Calculating sum, minimum, maximum, mean, median, and variance
- Transposing arrays using `np.transpose()` and `.T`
- Combining arrays vertically and horizontally using `np.vstack()` and `np.hstack()`

### 4. Axis Operations and Array Manipulation
- Performing calculations along rows and columns using `axis`
- Using `np.where()` for condition-based selection
- Finding unique elements with `np.unique()`
- Practicing array selection and manipulation techniques

### 5. Missing Values and Copy vs. View
- Identifying missing values using `np.isnan()`
- Counting missing values in arrays
- Calculating sums and means while ignoring NaN values
- Handling missing values using `np.nanmean()`, `np.nansum()`, and `np.nan_to_num()`
- Replacing missing values in arrays
- Understanding the difference between copying an array and creating a view using `.copy()`
